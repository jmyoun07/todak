### 토닥 동의문을 어떻게 고쳐야 하는지

| 판단 | 내용 |
|---|---|
| 입력 화면을 만들어야 하는가 | **아니요.** PHQ-9·GAD-7은 Google Survey로 수집하도록 IRB에 기재되어 있습니다. 앱에 입력 화면을 만들면 승인받은 절차와 달라집니다. |
| 항목을 빼야 하는가 | **'앱이 수집하는 항목'에서는 빼야 합니다.** 앱이 수집하는 것은 비식별 로그뿐입니다. PHQ-9·GAD-7 점수는 '연구 전체에서 수집되는 자료'로 위치를 옮겨 적는 것이 IRB 자료와 일치합니다. |
| 분류 표현 | 앱 동의문이 PHQ-9·GAD-7 점수를 '민감정보'로 분류했다면 IRB 문서에 대응 표현이 없으므로, 원문 표현인 '연구 자료: 설문 평가 결과(… 우울, 불안 …)'로 바꾸는 것이 안전합니다. |
| 앱 수집 항목 문구(그대로 사용 가능) | "총 접속 횟수, 사용 일수, 주간 사용 빈도, 질문 수, 평균 사용 시간 및 8주간 앱 사용 지속 여부를 비식별화된 앱 사용기록으로 수집합니다."(설명문 P99) |
| 반드시 포함해야 할 문장 | "질문 내용과 AI 답변의 원문은 연구용 앱 사용기록으로 수집하지 않습니다."(설명문 P101) |
| 추가 구현 요구 | 전자적 동의 완료 후 동의 내용과 연구설명문을 **확인하거나 저장**할 수 있는 기능이 있어야 합니다(동의서 8항, CRF 수정 대비표 P33). |

## 4. 연구계획서와 앱 화면이 어긋나는 곳

### (가) 앱 문안과의 대조

| 항목 | 연구계획서 | 앱 문구 쪽 확인 필요 사항 |
|---|---|---|
| PHQ-9·GAD-7 위치 | 온라인 설문으로만 수집, 앱은 비식별 로그만 | 앱 동의문이 이를 '앱이 수집하는 민감정보'로 적었다면 어긋납니다(3번 참조) |
| '민감정보' 용어 | 전문에 0건, '개인식별정보/연구 자료/앱 사용기록' 3분류 | 앱에서 '민감정보' 분류를 쓰면 대응 근거가 없습니다 |
| '비의료기기' 표현 | **전문에 0건.** 심의신청서 P44는 '□ 의료기기' 미체크 + '■ 기타: 어플리케이션'. 취지는 '참고용 건강정보 제공 도구', '환자교육 목적의 도구'로 표현 | 앱에 '비의료기기'라는 새 단어를 쓰면 IRB 문서에 없는 표현이 됩니다. 원문 표현 사용 권장 |
| 면책 문구 노출 | 심의의견: "…반복적으로 제시하실 필요가 있어 보입니다"(P24~25) | 동의 화면 1회로 끝내면 심의 요구와 어긋납니다. 단 '온보딩/배너/답변 하단' 같은 구체적 배치는 원문에 없는 해석입니다 |

※ 앱 화면의 실제 문구 파일을 직접 대조하지는 않았습니다. 위 4건은 '연구계획서에 이렇게 적혀 있으므로 앱 문구가 이와 다르면 어긋난다'는 기준입니다.
