# NCI PDQ, 써도 되는가 — 최종 판정

## 1) 한 줄 결론

**조건부 예.** 저작권상으로는 국내 어떤 소스보다 자유롭고(번역·재구성 명시 허용), 기전·원리 층은 그대로 쓸 수 있다. 그러나 **수치·약물명·비용·연락 안내 층은 "번역"이 아니라 "교체"** 대상이며, 이 구분 없이 직역하면 환자 안전 사고가 난다. 즉 **소스로는 채택, 번역기로는 불가**.

## 2) 층별 판정표

## 3) 한국화 체크리스트 (실무자용 — 콘텐츠 1건마다 그대로 실행)

### A. 삭제 스캔 (먼저 지운다)
- [ ] **모든 숫자에 형광펜.** 하나도 빠짐없이 검증 큐로. 통과 없이 화면에 못 올린다
- [ ] **화씨(°F) 검색** → 발견 시 재계산하지 말고 **국내 기준표에서 새로 가져온다**
- [ ] **파운드(lb)·인치·온스 검색** → 심부전 체중 기준("하루 2~3파운드") 같은 반올림 유입 차단
- [ ] **BMI 숫자 검색** → 미국 25/30 → 국내 **비만전단계 23 / 비만 25**로 교체
- [ ] **미국 상품명 검색**(Cytoxan, Taxol, Adriamycin, Miralax, Colace, Compazine, Marinol, Kepivance, Caphosol…) → 전부 치환 또는 삭제
- [ ] **비용·보험·재정 지원 문단** → 통째로 삭제
- [ ] **이미지·삽화·도표 인용** → 0건 확인

### B. 존재 검증 (한국에 있는가)
- [ ] 언급된 **약이 국내에 유통되는가** — prochlorperazine, dronabinol/nabilone은 없다 → 문장 삭제
- [ ] 언급된 **제품이 약국에서 살 수 있는가** — Miralax/Metamucil → 마그밀·둘코락스·듀파락·아락실
- [ ] 언급된 **처치가 국내에 개념으로 존재하는가** — magic mouthwash, Caphosol/Gelclair → 탄툼·헥사메딘·니스타틴·생리식염수/중조 가글
- [ ] 언급된 **서비스에 접근할 수 있는가** — 두피냉각, CLT 림프부종치료사 → "치료받는 병원에 보유 여부를 물어보세요"로 재작성
- [ ] **역방향 점검**: 한국에만 있어 NCI 자료가 못 다루는 것 — **미슬토 주사(압노바비스쿰·헬릭소·이스카도)**, 고용량 비타민C 주사

### C. 급여 필터 (가장 자주 놓치는 곳)
- [ ] 이 약은 국내 **허가**되었는가 / **급여**되는가 — 두 개는 다른 질문
- [ ] 급여면 → 산정특례 5% 안내 연결
- [ ] 비급여면 → "표준"이라는 단어를 쓰지 않는다
- [ ] **급여 상태는 유통기한이 있다.** 콘텐츠에 `급여 확인일: YYYY-MM-DD` 필드 필수 (엔허투 2024.4 급여, 버제니오 2026.5 암질심 통과 후 절차 진행 중 — 6개월이면 낡는다)

### D. 인구 보정
- [ ] 이 문장이 **"60대 은퇴 여성"**을 전제하는가 → 한국 독자는 **중앙연령 53.4세, 최다 40대(31.1%), 직장·육아 중**
- [ ] **폐경 전 여성 시나리오**가 빠지지 않았는가 (안면홍조·질건조·불임·골소실·난소기능억제)
- [ ] **다유전자검사 항암 생략 안내**에 **"50세 이하 주의"**가 붙어 있는가 — 없으면 오도
- [ ] **자가검진**: NCI/ACS 계열의 'breast awareness'를 직역하지 말 것. 한국 권고안은 **"매달 1회 시행"** 명문화
- [ ] **검진 연령**: "40세부터 매년" 직역 금지 → 한국 국가검진 **40세 이상 2년마다**

### E. 표기·거버넌스
- [ ] 필수 면책 문구(아래 5번) 삽입 확인
- [ ] 원문 URL + 원문 Updated 날짜 + 우리 Accessed 날짜 3종 병기
- [ ] `PDQ®`를 앱 메뉴명·아이콘·브랜딩에 쓰지 않았는지
- [ ] 결과물을 "NCI PDQ 요약"이라 부르지 않았는지
- [ ] **감수자 확인 항목(`⚑감수`) 목록이 별도로 뽑혀 있는지**

## 4) 위험한 오역 사례 5선

**① 발열 — "38도 이상"을 그대로 옮기면 액와 측정자가 사고를 낸다** *(가장 위험)*
NCI 원문: `fever of 100.5 °F (38 °C) or higher`. **측정 부위 표기가 아예 없다.** 한국 가정은 고막 체온계가 압도적이고 액와도 흔한데, 국내 기준은 고막 38.0 / **액와 37.5** / 구강 38.3이다. 액와로 37.7℃를 재고 "38도 아니네" 하고 넘어가는 호중구감소성 발열이 이 한 문장에서 발생한다. → **부위 명시 필수. NCI 문장 직역 금지.**

**② 설사 — 국내 연락 기준보다 3회분 늦다**
NCI 환자용 설사 페이지의 유일한 수치는 "Grade 3~4 = 하루 7회 이상 증가 시 생명 위협·입원 가능". 그 외엔 정성 서술뿐이고 **혈변·탈수·발열 동반 기준이 없다.** 국내/CTCAE는 **기저 대비 4~6회 증가(G2)부터 연락**. 직역하면 환자는 6회까지 참는다. → **NCI 설사 페이지를 근거로 삼지 말 것.**

**③ 체중 증가 "며칠 새 2kg" — 출처가 유방암이 아니다**
이 수치의 실제 뿌리는 미국 **심부전 확진자용** 자가모니터링 기준(하루 2~3파운드 / 주 5파운드)일 가능성이 높다. 문제 셋: (a) 심부전 환자 기준이지 항암 심독성 감시 기준이 아니다 (b) 파운드를 kg으로 반올림한 값이다 (c) 국내 종양간호 지침은 "평상시 체중 10% 이상 증가 + **하루 소변량 500cc 이하**"를 쓴다. → **2kg 삭제 또는 감수 대상.**

**④ Oncotype "점수가 낮으면 항암을 피할 수 있습니다" — 한국 독자 상당수에게 오도**
TAILORx RS 16–25는 전체로는 항암 이득이 없었으나 **50세 이하에서는 이득이 있었고**, MINDACT 8년 추적에서 임상고위험/유전자저위험군은 50세 초과 90.2% vs 90.0%(차이 없음)인 반면 **50세 이하 93.6% vs 88.6%(약 5% 차이)**. RxPONDER N1도 폐경 후는 생략 가능(GR A)이나 **폐경 전은 항암 병용 시 iDFS 89%→93.9%**. 한국은 최다 연령군이 40대다. → **"50세 이하 주의" 단서 없는 직역은 금지.** 덧붙여 국내에서 Oncotype은 **해외위탁 비급여 약 400만원**이고, 미국 자료에 없는 **진스웰BCT·온코프리**를 병기해야 한다.

**⑤ 미슬토 — 미국 근거로 답하면 국내 처방과 정면 충돌**
NCI PDQ는 미슬토를 **"FDA 미승인, 미국에서 상업적으로 구할 수 없음"**이라 명시한다. 그러나 국내에서는 **식약처 허가 전문의약품**으로 1994년부터 처방되어 왔다. 직역하면 "권장되지 않습니다"가 되어 **주치의가 지금 놓고 있는 주사를 앱이 부정하는** 상황이 된다. → **한국 전용 문장 필요**: "국내에서는 허가된 약이지만, 담당 종양내과와 상의하세요."

*(보너스: dronabinol/nabilone — NCI는 난치성 오심 옵션으로 다루나 국내는 마약류관리법상 희귀필수의약품센터 자가치료용 수입만 가능하고 승인 실적은 뇌전증 중심. 유방암 오심에는 사실상 접근 불가 → 해당 문단 전삭.)*

## 5) 필수 표기 문구 (확정안)

NCI 정책은 **번역물에 대해 면책 문구를 must로 규정**한다. 선택 사항이 아니다. 그리고 정확한 표현은 "승인하지 않았다(not approved)"가 아니라 **"보증하지 않는다(does not endorse)"**이므로 의역하면 정책 불이행이다. 정책이 언어를 지정하지 않으므로 **영문 원문 + 한국어 병기**가 안전하다.

### 앱 '자료 출처' 화면 / 콘텐츠 카드 하단 공통 푸터

```
본 자료는 미국 국립암연구소(National Cancer Institute, NCI)의 자료를
번역·각색한 것입니다.
(Adapted and translated from the National Cancer Institute.)

The National Cancer Institute (NCI) does not endorse this translation
and no endorsement by NCI should be inferred.
미국 국립암연구소(NCI)는 본 번역을 보증하지 않으며,
NCI의 보증이 있는 것으로 해석되어서는 안 됩니다.

원문: PDQ® [요약문 제목]. Bethesda, MD: National Cancer Institute.
Updated <MM/DD/YYYY>. https://www.cancer.gov/...
(Accessed <YYYY-MM-DD>)

본 자료는 원문 전체가 아니며 정기 갱신본이 아니므로
'NCI PDQ 암정보 요약'이 아닙니다.
최신·정확한 내용은 위 원문 링크에서 확인하십시오.

본 자료는 일반적인 정보 제공을 목적으로 하며,
국내 급여 적용 여부 및 개별 치료 계획은 담당 의료진과 상의하십시오.
```

### 배포 전 필수 확인 6항목
1. ☑ 영문 면책 문구를 **한 글자도 바꾸지 않고** 포함
2. ☑ "National Cancer Institute" 출처 명시(credit)
3. ☑ "adapted from" 개작 표기 포함
4. ☑ NCI 로고 미사용 / `PDQ®`를 브랜딩·아이콘·메뉴명으로 미사용
5. ☑ NCI 원문 이미지·삽화 **0건**
6. ☑ 원문 URL + 원문 Updated 날짜 + 우리 Accessed 날짜 3종 병기

| **"미국 자료를 무단 사용하는 것 아닌가?"** | NCI 재사용 정책(cancer.gov/policies/copyright-reuse, Reviewed 2025-03-12)은 텍스트에 대해 "free of copyright and may be reused without our permission"을 명시합니다. 번역·개작도 조항으로 명시 허용됩니다. **사전 허가 불요**이며, 요구되는 것은 출처 표시·개작 표시·면책 문구·로고 미사용뿐이고 모두 이행했습니다. |
| **"허가 서면을 받아왔는가?"** | 정책상 불필요하나, NCIinfo@nih.gov로 "본 사용은 NCI 재사용 정책 범위 내"라는 확인 회신을 받아 첨부하겠습니다. *(비용 0, 1주 내외. 이미 공개 허용이므로 거절될 구조가 없어 회신은 확인일 뿐입니다.)* |
| **"이미지는?"** | **0건입니다.** PDQ 요약문은 "Permission to use images outside the context of PDQ must be obtained from the owner(s) and cannot be granted by NCI"라고 명시하며, NCI조차 허락 권한이 없습니다. 앱 삽화는 전량 자체 제작입니다. |
| **"이걸 NCI 자료라고 표시하는 게 오해를 부르지 않나?"** | 그래서 "NCI PDQ 요약"이라 부르지 않고 **"NCI 자료를 번역·각색"**으로만 표기합니다. PDQ 상표를 브랜딩에 쓰지 않으며, 전문이 아니고 정기 갱신본이 아님을 화면에 자기고지합니다. |
| **"미국 기준이 한국 환자에게 위험하지 않나?"** *(핵심 질문)* | 정확한 지적이며, 저희는 **층별 판정 체계**로 대응합니다. 기전 층은 번역, **수치·약물명·비용·연락 안내 층은 국내 기준으로 교체**합니다. 구체적으로 발열(측정 부위), 설사(4회 vs 7회), 구토(NCI에 회수 임계 부재), 체중 증가(파운드 유래), BMI(23/25 vs 25/30), 다유전자검사 50세 이하 단서 — 6개 항목은 이미 국내 기준으로 확정 교체했습니다. 대조표를 부속서로 제출합니다. |
| **"한국어 공식판이 있는데 왜 직접 번역하나?"** | **PDQ에는 공식 한국어판이 존재하지 않습니다**(cancer.gov/publications/pdq/other-languages 확인). 대안인 국가암정보센터는 공공누리 **제4유형(상업적 이용 금지 + 변경 금지)**이라 요약·카드 재구성이 원천 봉쇄됩니다. 재구성이 정책상 허용되는 소스는 NCI가 유일합니다. |
| **"최신성은 어떻게 보장하나?"** | 원문 Updated 날짜와 우리 Accessed 날짜를 함께 표기해 갭을 스스로 공개합니다. 급여 정보는 별도 `급여 확인일` 필드로 관리하며 정기 갱신 주기를 SOP에 명시합니다. |
| **"의학적 감수는?"** | 국내 유방암 전문의 감수를 거치며, **`⚑감수` 태그 항목**(약물유전체 DPYD/UGT1A1 기술, 골다공증 치료 개시 기준, 체중 증가 임계 등)은 개별 승인 없이 배포하지 않습니다. |

**IRB에 먼저 제출할 것**: 「층별 판정표 + 국내/미국 Red Flag 수치 대조표 + 삭제 처리한 미국 전용 약제 목록」. 심의자가 가장 걱정하는 지점을 우리가 먼저 계량화해 제출하는 것이 가장 강한 대응입니다.

## 7) NCI만으로 부족한 부분 — 국내 소스로 보완할 목록

| 영역 | NCI의 공백 | 보완 소스 |
|---|---|---|
| **Red Flag 실행 수치** | 설사 임계 늦음, 구토 회수 임계 부재, 발열 측정 부위 부재, 소변량 정성 서술 | 국내 FN 지침(2011), 국내 종양간호 전화상담 지침, CTCAE, 삼성서울병원 환자교육, 질병관리청 국가건강정보포털 |
| **급여·비용** | 존재하지 않음 (미국 재정 체계 전제) | 심평원 암환자 약제 급여 세부기준, 산정특례, 암환자 의료비 지원사업 |
| **국내 유통 약 이름** | Cytoxan/Taxol/Adriamycin 등 미국명만 | 식약처 의약품통합정보(nedrug), 국내 병원 약물정보. **바이오시밀러(허쥬마·삼페넷·온트루잔트), 롤론티스, 제넥솔PM은 NCI에 아예 없다** |
| **미국에 없는 국내 처치** | 미슬토, 고용량 비타민C 등 대응 항목 없음 | 한국유방암학회 권고안, 국내 병원 자료. 미슬토는 **한국 전용 문장** 필요 |
| **다유전자검사** | 미국은 Oncotype/MammaPrint만, 급여 전제 | 진스웰BCT·온코프리 병기, 심평원 해외위탁 비급여 결정, **"50세 이하 주의" 단서** |
| **추적관찰·자가검진** | ACS는 정기 자가검진 권고 철회 → 직역 시 국내 권고안과 충돌 | 한국유방암학회 권고안 제2장 2.4 (**매달 자가검진**, 치밀유방+50세 이하+유방보존술 이력자 연간 MRI 고려) |
| **검진 안내** | 기관별 편차 큼(USPSTF/ACS/ACR/NCCN) | 국가암검진 **40세 이상 2년마다 유방촬영술** |
| **인구 특성** | 중앙연령 64세, 45세 미만 10.6% 전제 | KBCS 등록사업 — 중앙연령 53.4세, 40대 31.1%. **폐경 전 여성 시나리오를 국내 자료로 신규 작성** |
| **체격·BMI** | 25/30 기준 | 대한비만학회·WHO 서태평양 기준 23/25. 타목시펜 지방간은 **BMI ≥22에서 이미 위험 증가(HR 1.58)** |
| **접근성 의존 서비스** | CLT·두피냉각을 있는 것으로 전제 | 국내 보유 병원 현황 확인 후 "물어보세요" 구조로 재작성 |
| **한국어 문장 톤** | 공식 한국어 PDQ 없음 → 전량 자체 번역 | 국가암정보센터는 **참고만 가능(제4유형, 변경 금지)**. 문장 재사용 불가 |

**보완 우선순위**: ① Red Flag 수치표 확정 → ② 약물 별칭 DB(성분명 키 + 국내 상품명 + 구어 "빨간약"/"에이씨") → ③ 급여 상태 필드 + 갱신 SOP → ④ 폐경 전/40대 시나리오 신규 작성.

---

**최종 운영 규칙 한 줄**: NCI는 **"왜 이런 일이 생기나"의 소스**로 쓰고, **"그래서 몇 도에 어디로 전화하나"는 국내 자료로만** 쓴다.
