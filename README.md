# 토닥 (Todak) — 유방암 부작용 AI 에이전트 앱

유방암 환자의 항암 부작용 자기관리를 돕는 웹/안드로이드 앱과, 해당 임상연구 자료 모음.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `1_배포파일` | 안드로이드 APK, 웹 배포본(HTML/JS 253파일), 정식배포 절차 문서 |
| `2_연구_IRB` | IRB 승인서·연구계획서·CRF, 내용타당도 평가지, AI 응답 검증 기록, 앱 고지 점검 |
| `3_안내문서` | 기능정의서, 기술명세서 v2.0, 사용설명서, 설치안내문, 소개서, 연구참가신청서 서식 |
| `4_콘텐츠근거` | 국제출처 22종 매핑, RedFlag 기준표, 식사카드 근거, 화면별 출처표 |
| `5_디자인` | 로고, 로그인 버튼, 화면 시안 |
| `6_외부연동_검수` | 네이버 로그인 검수 자료, 건강보험심사평가원 OpenAPI 가이드 |
| `7_DB_수파베이스` | Supabase 스키마, 보안 수정 SQL, 환자확인서류 설정 문서 |
| `8_개발도구` | 아이콘·문서·웹 빌드 스크립트 (Python) |
| `UI 결과물` | 화면 캡처, overview HTML, 출시안 |
| `피드백` | 사용자/연구팀 피드백 |

## 참고

`1_배포파일/토닥_웹배포.zip` 안의 `js/config.js`에는 Supabase publishable 키, 네이버 Client ID,
카카오 JavaScript/REST 키, 웹푸시 VAPID 공개키가 들어 있다. 모두 클라이언트에 배포되는 공개값이며
DB 비밀번호·service_role 키·OAuth Client Secret은 들어 있지 않다.
단 카카오 REST 키는 서버용 키라 노출 범위를 한 번 점검할 필요가 있다.
